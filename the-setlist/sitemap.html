Archivos compartidos por todas las páginas

CSS

  • variables.css — tokens de diseño (colores, tipografía, espaciado)
  • style.css — estilos globales, componentes, responsive breakpoints

JavaScript

  • data.js — servicios, paquetes, imágenes, credenciales, localStorage helpers
  • app.js — lógica del catálogo, presupuesto, paquetes, hamburger, drawer
  • checkout.js — lógica del formulario, dropzone, confirmación
  • admin.js — auth, tablas, CRUD servicios, gestión de órdenes

Persistencia

  • localStorage → ts_services (servicios editados)
  • localStorage → ts_orders (órdenes guardadas)
  • sessionStorage → ts_selected (servicios seleccionados en checkout)
  • sessionStorage → ts_admin_auth (sesión admin)
